# DragonBound Companion Extension

Extension sencilla para Chrome que agrega un panel flotante en `dragonbound.net`.

Incluye:

- Notas manuales guardadas localmente.
- Cronometro con iniciar, pausar y reiniciar.
- Contador de turnos.
- Boton para minimizar el panel.

No lee datos internos del juego, no automatiza acciones, no mueve el mouse, no modifica el canvas y no intercepta red.

## Instalacion

1. Abre `chrome://extensions` en Chrome.
2. Activa `Developer mode`.
3. Pulsa `Load unpacked`.
4. Selecciona esta carpeta: `dragonbound-companion-extension`.
5. Abre `https://dragonbound.net/`.

El panel aparecera en la esquina inferior derecha.
